
# Multi-page Personal Portfolio

## Introduction

This project is a basic personal portfolio website
developed using HTML5.

It contains multiple interconnected webpages
to showcase personal information, education,
skills, projects and contact details.

## Objectives

- To learn the basics of web development.
- To understand HTML5 elements.
- To create multiple webpages.
- To use hyperlinks for navigation.
- To understand Git and GitHub.

## Technologies Used

- HTML5
- Git
- GitHub

## Pages

1. Home
2. About
3. Skills
4. Projects
5. Contact

## Features

- Multiple interconnected webpages.
- Navigation menu using hyperlinks.
- Semantic HTML5 elements.
- Organized webpage structure.

## How to Run

Open index.html in any web browser.
